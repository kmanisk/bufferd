# Contributing

Contributions are welcome. Keep each pull request focused on one logical change.

## Workflow

1. Branch from `main`.
2. Follow the setup and run instructions in `README.md`.
3. Make the smallest change that solves the problem.
4. Run the relevant formatter, linter, and tests before submitting.
5. In the pull request, explain the problem, the change, and how it was verified.

Please do not commit credentials, generated build artifacts, local caches, or editor-specific files. Bug reports should include reproduction steps, expected behavior, actual behavior, and relevant environment details.
